# API de tareas

Este trabajo consiste en una API desarrollada con Node.js y Express que nos dejaría administrar tareas por diferentes rutas. Incluye funciones para registrar usuarios, iniciar sesión, crear, consultar, actualizar y eliminar tareas. También hay cuenta con autenticación mediante tokens para proteger el acceso a las rutas y usar archivos JSON para guardar la información.

## Cosas que utilicé
- Node.js
- Express
- bcryptjs
- jsonwebtoken
- JSON
